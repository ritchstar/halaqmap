# حصر الملكية الفكرية لمنتجات خريطة الحل

**الغرض.** إثبات تعبير برمجي أصلي لكل **مصنف مستقل** جاهز لتقديم SAIP: المزايا، أدوات التشغيل، المسارات، رموز الكود، الجداول، وسم الدفع، وبيان المؤلف.

**المؤلف الوحيد.** احمد بن عبداللة بن عبداللة بن سراء / `BINSARRA AHMED ABDULLAH A` / هوية 1047848245. المرجع: [`بيان-المؤلف.md`](بيان-المؤلف.md). اسم GitHub `ritchstar` مستعار للحساب وليس اسم المؤلف في الطلب. Cursor أداة مساعدة وليست مؤلفاً مشاركاً.

**صاحب الحق التجاري.** متجر التجزئة للبرمجيات `halaqmap`، الاسم الظاهر خريطة الحل. المنتج البرمجي الأول: منصة حلاق ماب. الرقم الوطني الموحد مرجع السجل لا يُدرج هنا كسرّ تشغيل. الإدارة لا المؤسس في نصوص الزائر.

**ما ليس هذا المجلد.** ليس نقل ملكية لمكتبات الطرف الثالث. ليس كشفاً لأسرار. ليس بديلاً عن الشروط والخصوصية. الحملات والعمولة الداخلية للمتجر **ليست مصنفات مستقلة**.

**التحديث.** كل مصنف مستقل ملف باسمه. الحملات الترويجية تُحدَّث داخل [`متجر-خريطة-الحل.md`](متجر-خريطة-الحل.md). القالب: [`_قالب.md`](_قالب.md). قاعدة الوكيل: `.cursor/rules/fkrih-ip.mdc`.

**تاريخ إنشاء الحصر الأول.** 28 آب / أغسطس 2026.

**حزم المصدر للطلبات.** فحص أسرار ثم PDF لكل مصنف مستقل في `fkrih/saip-pack/`. المخرجات المحلية: `fkrih/saip-pack/out/`. حد البوابة 1024 ميغابايت. الحملات الترويجية ليست مصنفات منفصلة.

## قاعدة العزل للدفع
