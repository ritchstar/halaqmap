# سفراء حلاق ماب

بوابة ميدانية لأول تفعيل منشأة حلاقة. ليست مسوّقي منتجات المتجر وليست مسوّقات كوافير ماب.

## 1. الهوية

مسارات `/ambassadors` والدخول والقواعد والتدريب. سياسة `ambassadorFieldRulesPolicy.ts`. SQL `138_ambassador_field_program.sql` وما يليها. وثائق `docs/ambassadors/`.

## 2. العمولة

أول تفعيل فقط بلا تجديد. شرائح برونزي/ذهبي/ماسي حسب مدة الرخصة (مثال الحصر التشغيلي: برونزي 100–1200، ذهبي 150–1600، ماسي 200–1600 حسب 1/3/6/12 شهراً). مسار ضيافة +25 ر.س عند الإغلاق. مطابقة جغرافية الهدف والتسجيل ضمن خمسين متراً.

## 3. أدوات التشغيل

تقديم `ambassador-apply.ts`، مراجعة `admin-ambassador-applications.ts`، لوحة السفير، شرائح تدريب، عدة تسويق `ambassadorMarketingKit.ts`. اختبار `scripts/test-ambassador-commission-table.mts`.

## 4. الحدود

لا استهداف صالون من بوابة المتجر الإلكتروني. لا عمولة على تجديد الرخصة. لا عمولة منتجات `store_*`.
