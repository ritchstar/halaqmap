# تمهيد تقديم SAIP — حلانا1

هذا التمهيد يجهّز حزمة المصدر لطلب حماية البرنامج لدى الهيئة السعودية للملكية الفكرية. ليس الطلب نفسه، ولا يُرفع قبل فحص الأسرار وتوليد PDF من `generate_saip_product_pdfs.py`.

## المصنف

| الحقل | القيمة |
|-------|--------|
| الاسم الظاهر | حلانا1 |
| الوسم | `store_halana_live` |
| العائلة | صفحة-حي |
| ملف الحصر | [`../حلانا1.md`](../حلانا1.md) |
| قاعدة الوكيل | `.cursor/rules/store-halana-live.mdc` |
| المؤلف | احمد بن عبداللة بن عبداللة بن سراء / BINSARRA AHMED ABDULLAH A |
| رقم الشهادة | لم يصدر بعد. لا يُذكر في الفوتر العلني |

## ما يُضمَّن في الحزمة

- ملف الحصر `fkrih/حلانا1.md`
- إعداد المنتج ومسارات الواجهة والهبوط والدفع والـ API والهجرة والاختبار
- قاعدة المنتج `.cursor/rules/store-halana-live.mdc`
- خطاب سرية لاستبعاد الأسرار ومفاتيح التشغيل

## ما يُستبعد

- مفاتيح ميسر وSupabase وResend وأي `.env`
- سجلات تشغيل أو بيانات عميلات
- آيبان أو إثبات تحويل
- مصنفات أخرى: طبختنا1 وتمويناتا1 ومطعمنا1 وكافينا1 وخضارنا1

## خطوة التوليد

من جذر المستودع بعد فحص الأسرار:

`python fkrih/saip-pack/generate_saip_product_pdfs.py --product halana1`

المخرج المحلي: `fkrih/saip-pack/out/halana1/`. حد البوابة 1024 ميغابايت.

## ملاحظة التقديم

حلانا1 برنامج صفحة حي قائم بذاته: معرض أعمال وصفحة طلب مخصص ولوحة متخصصة ووسم دفع مستقل لاشتراك المشغّلة. ليس جلداً فوق طبختنا1. لا تحصيل من العميلة عبر ميسر. التجربة والترشيح التقني جزء من تشغيل المتجر وليست مصنفاً منفصلاً.
