# حزم مصدر SAIP — مصنف لكل طلب

كل مصنف مستقل في `fkrih/00-فهرس.md` يُفحص ثم يُحوَّل إلى **PDF واحد** تحت حد بوابة SAIP (1024 ميغابايت). الحملات الترويجية ليست مصنفات مستقلة وتبقى داخل حزمة متجر خريطة الحل.

## التشغيل

من جذر المستودع:

```
python fkrih/saip-pack/generate_saip_product_pdfs.py --scan-only
python fkrih/saip-pack/generate_saip_product_pdfs.py
python fkrih/saip-pack/generate_saip_product_pdfs.py --product afrahi1
```

المخرجات المحلية (لا تُرفع إلى Git): `fkrih/saip-pack/out/<slug>/<slug>-saip-source.pdf`

## الفحص

يُرفض التوليد إذا وُجد في الملفات المختارة: آيبان سعودي مكتمل، مفتاح ميسر حي/تجريبي، معرف تويلو، مفتاح خاص PEM، مفتاح AWS، رمز GitHub، JWT طويل، أو كلمات دخول تجريبية.

يُستبعد: `node_modules` و`.env` ومخرجات البناء وملفات الحساب البنكي وملاحظات الدخول ومجموعات بوستمان غير المتتبَّعة.

## الرفع

ارفع PDF ذلك المصنف فقط في طلبه. لا ترفع ZIP. لا تخلط مصنفين في مرفق واحد.
