- تم التحقق فعليًا من أن الـ patch يُطبَّق بنجاح على نسخة نظيفة من هذا الـ commit (`git am --binary`) وأن الصور الناتجة سليمة (WebP صحيحة 1024×1024 لكل الملفات العشرة) قبل تسليمه.

## خطوات التطبيق

```bash
cd halaqmap   # مجلد المستودع المحلي لكروسور
git fetch origin
git checkout main
git pull --ff-only origin main   # تأكد أنك على أحدث main فعليًا

# إن كان main قد تقدّم عن 56858c9 منذ هذا التسليم، طبّق الـ patch على فرع جديد أولاً بدل main مباشرة، وراجع التعارضات إن وُجدت:
git checkout -b feature/solution-catalog-hero-cards

git am --binary /path/to/0001-Replace-solution-catalog-rows-with-full-image-produc.patch
```

إذا نجح `git am` دون تعارضات (وهو المتوقع إن كان `main` لا يزال عند `56858c9` أو لم تُعدَّل نفس الملفات):

```bash
# تحقق سريع

npm run build   # أو أي فحص type-check/lint معتمد في المشروع

# ثم ادفع

git merge --ff-only feature/solution-catalog-hero-cards   # أو ادفع الفرع مباشرة وافتح PR حسب سياسة الفريق
```

إذا ظهر تعارض (لأن `main` تغيّر عن `56858c9`)، أفضل حل هو `git am --abort` ثم إعادة تطبيق التعديلات يدويًا بالاعتماد على الوصف أدناه بدل محاولة حل تعارض ثنائي (binary) في الصور.

## ماذا يغيّر هذا الـ commit فعليًا

- `src/config/storeSolutionCatalog.ts`: إضافة حقل `cardImageSrc` ودالة `solutionCatalogCardImageSrc(code)` (نمط `/images/store/catalog/cards/{code}.webp`)، مربوطة بكل المنتجات العشرة.
- `src/components/store/catalog/SolutionCatalogProductCard.tsx` (**ملف جديد**): بطاقة صورة كاملة — صورة الخلفية + تدرّج داكن (`wash`) + اسم المنتج بخط كلاسيكي (Georgia/Times) للجزء العربي وخط حديث بارز للرقم اللاحق إن وُجد، مع بديل ورقي (الحرف الأول) في حال تعذّر تحميل الصورة (`sanitizeStoreProductImageSrc`). الضغط على البطاقة بأكملها يفتح نافذة تفاصيل المنتج (`onOpen`) — نفس سلوك زر "افتح بطاقة المنتج" القديم.
- `src/components/store/catalog/SolutionCatalogApp.tsx`: استبدال صفوف القائمة القديمة (`ProductMark` + نص + زر) بشبكة (`grid`) من `SolutionCatalogProductCard`. **`ProductMark` لم يُحذف** — لا يزال مستخدَمًا في أعلى نافذة تفاصيل المنتج (`ProductModal`) كشارة صغيرة بجانب العنوان.
- `src/styles/storeSolutionCatalog.css`: إضافة أنماط الشبكة والبطاقة الجديدة، وحذف أنماط `.solution-catalog__row` القديمة (لم تعد مستخدمة بعد هذا التعديل).
- `public/images/store/catalog/cards/{a-01,a-02,b-01,b-02,c-01,c-02,d-01,d-02,d-03,e-01}.webp`: الصور العشر (1024×1024 WebP)، توليد أصلي (AI) بأسلوب تعبيري موحّد يعكس نشاط كل منتج.

## بعد الدفع

- تحقّق من صفحة الفهرس (`/store/catalog-lab` — المسار المعرّف في `STORE_SOLUTION_CATALOG_LAB_PATH`) وتأكد أن كل بطاقة من العشرة تعرض صورتها الصحيحة، وأن الضغط عليها يفتح نافذة التفاصيل بشكل طبيعي.
- لا حاجة لأي تعديل إضافي على المسارات (`href`) — هذا التسليم لا يمسّ منطق التنقل إطلاقًا، فقط طبقة العرض.
