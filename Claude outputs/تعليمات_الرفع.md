# تعليمات رفع تحديث Chatly — طبختنا1 وتمرتنا1

هذا الملف يشرح كيف تنسخ ملفات هذا التحديث إلى مشروع Cursor وترفعها إلى GitHub.

## ما الجديد

أُنجزت تجربة Chatly الكاملة (واجهة زبون + لوحة تشغيل بتصميم "الكتالوج الورقي" الدافئ) لكل من:

- **طبختنا1 (Kitchen)** — آخر التحقق من الميزات الحقيقية: طلب اليوم، تفعيل/إيقاف نفاد، الجدولة، صورة التوصيل، رسوم التوصيل، تذكرة الاستلام (Ready) مع رسالة واتساب التلقائية، تجديد/إبطال رمز QR، شريط حملة الهدية، زر مركز النمو. لا صندوق محادثة ولا نظام بائع متحرك (لأن طبختنا1 لا يملكهما أصلاً).
- **تمرتنا1 (Dates)** — التحقق شمل: نظام البائع المتحرك الكامل (ثابت/متحرك، مسار العربة، جدول الأسبوع، سجل التحديثات)، خدمة "تعال" الفريدة (تنبيه اقتراب العربة عبر إشعار المتصفح)، التسعير بالوحدة (كيلو/صندوق/كيس/علبة)، قسم "وصل اليوم" المستقل، وصندوق المحادثة الدائم (غير قابل للإخفاء، خلافاً لبقية المنتجات).

كلا المنتجين يعملان بنفس منطق الطلب والدفع والتخزين الحقيقي — لم يتغيّر أي شيء في الـ backend أو Supabase، فقط الواجهة الأمامية الجديدة تُفعَّل عبر مفتاح Chatly (مفعّل افتراضياً للجميع حالياً، مع إمكانية الرجوع الطارئ عبر متغيرات البيئة).

## خطوات الرفع عبر Cursor

1. افتح مشروع halaqmap في Cursor.
2. انسخ كل ملف من القائمة أعلاه إلى مساره المطابق تماماً (أنشئ المجلدات `src/components/store/kitchen/` و`src/components/store/dates/` إن لم تكن موجودة أصلاً — لكنها موجودة أصلاً لأن كلا المنتجين لهما ملفات سابقة).
3. تأكد أن `src/index.css` يحوي أسطر الاستيراد الأربعة المذكورة أعلاه.
4. نفّذ:
   ```bash
   git add -A
   git status   # راجع أن كل الملفات المتوقعة ظاهرة كـ new file / modified
   git commit -m "إضافة تجربة Chatly الكاملة لطبختنا1 وتمرتنا1"
   git push
   ```

بعد الرفع، أخبرني وسأتحقق مباشرة من GitHub أن كل شيء وصل بسلامة كما فعلنا مع كافينا1.
