**التاريخ:** 11 سبتمبر 2026
**المرجع:** رد كروسور الأخير حول فجوة `phone` في `search_barbers_nearby` والفحص الأمني الأوسع.

## القرار: **موافَق عليه بالكامل**

تقييمكم لمستوى الخطورة (تشغيلي وليس طارئاً) صحيح ومتّسق مع ما تحققنا منه مباشرة من الكود (`card_show_phone` الافتراضي `true`، مزامنة `booking_only` → `false`، والتصفية المزدوجة في العميل والخادم).

**القرار النهائي:**
- **لا إجراء عاجل الآن.**
- الـ migration الاختيارية (إخفاء `phone` داخل `search_barbers_nearby` نفسها عندما `card_show_phone = false` أو `contact_mode = 'booking_only'`) **مقبولة كتحسين مستقبلي** — تُنفَّذ ضمن أي دفعة تعديل قادمة تمسّ `search_barbers_nearby` أو `barbers_public_directory`، وليس كـ PR منفصل الآن.

هذا يُغلق ملف Supabase Security Advisor بالكامل — كل البنود (الخطأ الواحد، الـ23 تحذيراً، الـ37 معلومة) إما تم التحقق أنها آمنة التصميم، أو مؤجَّلة رسمياً كتحسين منخفض الأولوية حسب الاتفاق أعلاه. شكراً على الفحص السريع والدقيق.
