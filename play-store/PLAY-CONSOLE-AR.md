### لقطات الشاشة — مطلوب قبل المراجعة النهائية

اللقطات الحالية مقصوصة من واجهات تسويقية قديمة وقد تظهر شريط متصفح/أدوات.  
**قبل الإرسال للمراجعة:** التقط من الجهاز الحقيقي أو المحاكي واجهات الإنتاج التالية (بدون شريط Chrome):

1. شاشة دخول تطبيق الصالون `/#/partners/app` أو `/#/partners/login`
2. لوحة تحكم الصالون `/#/barber/dashboard`
3. البحث/الخريطة أو مسار الشريك (واجهة واضحة للمنتج)
4. (اختياري) الحجز بالاسم / المواعيد إن وُجدت في الحساب التجريبي

متطلبات Google: من 2 إلى 8 لقطات هاتف، نسبة عمودية مناسبة، بدون إطارات جهاز إلزامية.

## 4) استبيان أمان البيانات (Data Safety) — إجابات تقنية معتمدة

طبّق الإجابات التالية بما يطابق تشغيل TWA + الموقع الحي. راجعها قبل الإرسال إن تغيّر السلوك.

### هل يجمع التطبيق بيانات أو يشاركها؟
**نعم** (حساب شريك، بيانات تشغيل، وموقع لحظي عند الإذن عبر الويب داخل الغلاف).

### الموقع الجغرافي (Location)

| سؤال Console | الإجابة المعتمدة |
|--------------|-------------------|
| هل يجمع Approximate / Precise location؟ | **نعم — الموقع التقريبي و/أو الدقيق عند منح الإذن** (عبر Geolocation في المتصفح داخل TWA) |
| هل يُجمع في الخلفية؟ | **لا** — فقط أثناء الاستخدام النشط وبعد موافقة المستخدم |
| الغرض | **وظائف التطبيق** (عرض الصالونات/الخدمات القريبة وربط المستخدم بالمتاح حوله) |
| هل يُشارك مع أطراف ثالثة؟ | **لا** لأغراض إعلانية/تسويقية |
| هل مشفر أثناء النقل؟ | **نعم** (HTTPS / TLS) |
| هل يمكن للمستخدم طلب الحذف؟ | بيانات الموقع **لحظية وغير مخزّنة كسجل تاريخي**؛ سحب الإذن من إعدادات الجهاز يوقف الجمع. باقي البيانات الشخصية عبر قنوات الدعم وفق السياسة |

نص توضيحي للمراجع:

> Location is requested only with user consent, processed in real time to show nearby salons/services, and is not stored as a historical location trail in the platform database. See privacy policy.

### بيانات أخرى محتملة (عبّئها إن طُلب التفصيل)

| نوع البيانات | يجمع؟ | الغرض | ملاحظات |
|--------------|--------|--------|---------|
| معلومات الحساب / البريد | نعم (مسار الشريك) | إنشاء الحساب / الدخول / التواصل التشغيلي | وفق خصوصية الشركاء |
| رقم الهاتف | نعم (تسجيل/تواصل) | التحقق والتواصل مع الصالون | |
| بيانات مالية للدفع | الدفع عبر متصفح خارجي / بوابات دفع | شراء الرخص/الاشتراك | Play Billing **غير مفعّل** في TWA (`playBilling.enabled: false`) |
| معرفات الجهاز / الإشعارات | إشعارات اختيارية | تنبيهات تشغيلية للصالون | صلاحية `POST_NOTIFICATIONS` في Manifest |
| الصور / مرفقات التسجيل | نعم عند التسجيل | اعتماد الصالون | عبر مسار التسجيل الآمن |

### الأمان والممارسات

- تشفير أثناء النقل: **نعم**

- الالتزام بسياسة العائلات: غير موجّه للأطفال — الفئة المقترحة: أدوات أعمال / نمط حياة حسب التصنيف الأنسب في Console

## 5) خطوات النشر والمراجعة (نفّذ بالترتيب)

### أ) اختبار داخلي (موصى به أولاً — ساعات لا أيام)
1. Play Console → التطبيق `com.halaqmap.partner` (أنشئ التطبيق إن لم يُنشأ).
2. **الاختبار → الاختبار الداخلي → إنشاء إصدار**.
3. ارفع `play-store/delivery/halaqmap-partner-1.0.0-vc2.aab`.
4. أضف مختبرين داخليين (بريد Google).
5. أكمل: سياسة الخصوصية، أمان البيانات، تصنيف المحتوى، الجمهور المستهدف، إعلانات (إن وُجدت).
6. ارفع الأيقونة + Feature Graphic + لقطات هاتف محدّثة.
7. ابدأ طرح الاختبار الداخلي وتحقق من التثبيت وفتح `/#/partners/app` بدون شريط Chrome (تحقق Asset Links).

### ب) الإنتاج / المراجعة النهائية
1. بعد نجاح الاختبار الداخلي: **الإنتاج → إنشاء إصدار** من نفس الـ AAB (أو بناء أحدث).
2. أرسل للمراجعة.
3. بعد القبول انسخ رابط المتجر وثبّته في الكود:

```ts
// src/config/partnerAppShell.ts
export const PARTNER_ANDROID_PLAY_STORE_URL =
  'https://play.google.com/store/apps/details?id=com.halaqmap.partner';
```

**العنوان القصير (≤30):** `حلاق ماب — تطبيق الصالون`

`لوحة تحكم الصالون وإشعارات فورية وربط العملاء القريبين عبر حلاق ماب.`
